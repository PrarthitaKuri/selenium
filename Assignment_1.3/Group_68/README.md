## 📌 Project Overview

This repository contains our collective project files, scripts, and automation tasks developed as part of the **Python Automation Course** curriculum. The focus of this project is on mastering **Selenium WebDriver** fundamentals — from locating elements to handling complex, dynamic web pages.

---

## 🎓 Course Outcomes

By the end of this course/project, we are able to:

- 🔍 **Identify web elements** — Understand web elements and their attributes on a web page.
- 🎯 **Use Selenium locators** — Locate elements using `ID`, `Name`, `Class Name`, `Tag Name`, and `Link Text`.
- 🖱️ **Interact with elements** — Find and interact with both single and multiple web elements effectively.
- 🧩 **Master CSS Selectors** — Create and apply CSS Selectors, wildcards, and child-node selectors for complex elements.
- ⚡ **Handle dynamic elements** — Select appropriate, reliable locators to manage dynamic and challenging elements in automation.
